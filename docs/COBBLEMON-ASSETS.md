# Cobblemon graphic data in the VASC base pack

Original author/publisher: the Cobblemon team and contributors.
Source: https://gitlab.com/cable-mc/cobblemon
Pinned revision: 0bc5bb5caaca5622c9f1856cadd866ad85d21287

The included JSON model, animation, poser and resolver data and PNG textures
are byte-for-byte copies of that revision, limited to the selected catalog.
No Java classes or upstream executable scripts are included.
All per-model license files are retained in their original directories;
these licenses govern their associated assets. This inclusion does not
relicense those assets under VASC's code license. Source paths and SHA-256
checksums for every file are recorded in assets/cobblemon-catalog.json.
Ascendant-authored additions remain in assets/cobblemon-ascendant.

The only packaging change is local availability, replacing thousands of
individual HTTP transfers. Model conversion happens locally at installation.
