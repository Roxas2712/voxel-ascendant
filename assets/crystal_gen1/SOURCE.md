# Gen-I Crystal battle-art subset

This directory is a byte-for-byte copy of the Gen-I subset shipped by Kanto
Ascendant 6.5.2. Kanto Ascendant's own files remain in its package; Voxel
Ascendant neither moves them nor reads them at runtime.

Included:

- 2,323 normal and 2,323 shiny Crystal front-animation frames for Dex 1–151;
- 151 normal and 151 shiny Crystal rear cards for Dex 1–151;
- 47 normal Crystal trainer portraits;
- the upstream v1.5 provenance record.

The sorted SHA-256 file-list receipt used for this import contains 4,996
entries and has SHA-256
`a53dd91c642a513f6ceeda1b92d2e5a35805f53b2f1b3fbaaf8a68e92f64ab0e`.
The animation timing table is stored separately as
`data/crystal_gen1_timing.lua`.
